## Scripts

| Script | Description | Documentation |
|---|---|---|
| YouTube Rotate Video 90° | Rotate videos left or right. | [Installation and tests](youtube-rotate/README.md) |

## Compatibility

The YouTube script has been tested in real-world use on **Firefox only**. Additional local fixture tests were run in an embedded browser; they do not establish Chrome, Edge or Safari compatibility.
